# Security Audit Checklist (`SECURITY_CHECKLIST.md`)

This document records our two-pass application security review against every control in `<security_requirements>` and Sections 7, 8, and 13 of *Mini Project 01 – Employee Self-Service Portal*.

- **Audit Rule**: A control is marked **PASS** only when both the production source code location AND an automated test proving it are present and passing in this repository. Controls that depend on live cloud infrastructure (e.g., Supabase PostgreSQL RLS enforcement on the remote server or a 25-user load test against a remote Supabase instance) are honestly marked **PARTIAL** with full SQL/code evidence and notes.
- **Audit Passes**:
  - **Pass 1 (Post-Build Review)**: Identified that test rate-limiter defaults needed alignment across test suites and verified that `SYSTEM_ADMIN` role was explicitly excluded from `/api/payslips` and `/api/leaves/*` routes to enforce strict separation of duties.
  - **Pass 2 (Post-Fix Verification)**: Re-ran `npm test` (30/30 tests passing), verified zero `dangerouslySetInnerHTML`, zero `localStorage` token storage, and empty `.env` files.
